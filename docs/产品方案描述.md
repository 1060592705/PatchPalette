# 🧵 手工灵感管理与电子拼布 — 产品方案描述

## 这个 App 是做什么的？

一个帮助你收集手工灵感、管理布料库存、并且在手机上预览拼布效果的随身工具。

**iPhone 上像普通 App 一样使用**（添加到主屏幕），所有数据存在你手机里，离线也能用。

---

**标签说明：**

### 3.3 布料库存追踪

每块布料会记录：
- **总面积**：宽 × 长
- **已用面积**：在拼布方案中被使用的面积
- **剩余可用**：总面积 － 已用面积
- 当某块布剩余不足时，会标注"库存紧张"

## 四、电子拼布 — 核心创新功能（第二期）

### 4.1 完整拼布流程

```
拍照导入纸样 → 自动识别区块 → 手动修正(如需) → 
关联包包教程 → 设定拼布区域尺寸 → 设定缝份 →
点区块选布料 → 实时预览效果 → 确认方案 →
📊 自动生成用料清单
```

### 4.2 纸样拍照与区块识别

```
┌─────────────────────────────────┐
│  ← 新建拼布方案                   │
│                                 │
│  第1步：导入纸样                  │
│                                 │
│  📷 拍照 或 从相册选择            │
│                                 │
│  [纸样照片显示区域]               │
│                                 │
│  第2步：自动识别                  │
│  [开始识别]                      │
│                                 │
│  识别完成后：                     │
│  ┌─────────────────────────┐    │
│  │ 纸样上叠加彩色区块       │    │
│  │ 红色轮廓线标出每个区块   │    │
│  └─────────────────────────┘    │
│                                 │
│  [✏️ 手动修正] [✅ 确认]         │
└─────────────────────────────────┘
```

**手动修正功能：**
- 合并两个相邻区块（点一下中间的线）
- 拆分区块（在区域内画一条分割线）
- 调整边界点（拖动轮廓节点）

### 4.5 用料清单 — 精打细算

确认拼布方案后，一键生成的报告：

```
┌─────────────────────────────────┐
│  📊 用料清单 — 托特包拼布方案      │
│                                 │
│  —— 所需布料汇总 ——              │
│  碎花棉布    需要 120cm²  ✅ 够用 │
│  红色波点布  需要 85cm²   ✅ 够用 │
│  牛仔布      需要 200cm²  ⚠️ 不够 │
│                                 │
│  —— 库存剩余预估 ——              │
│  碎花棉布    2500cm² → 2380cm²  │
│  红色波点布  2700cm² → 2615cm²  │
│  牛仔布      8000cm² → 7800cm²  │
│                                 │
│  —— 🛒 需要购买 ——              │
│  牛仔布  至少再买 10cm×10cm      │
│  🔗 购买链接 →                   │
│                                 │
│  [📤 导出分享]                   │
└─────────────────────────────────┘
```

**计算逻辑：**
1. 每个区块的面积（cm²）× 布料单价 = 用量
2. 加上缝份的额外面积
3. 同一块布被多个区块使用 → 合并计算
4. 对比库存 → 哪些够、哪些不够
5. 不够的生成购物清单，附带之前存的购买链接

## 五、两层选布系统

拼布 App 里有两层选布，共用同一套"划区域 → 选布 → 预览 → 计算"逻辑：

```
           🧵 布料库
          ╱          ╲
    包包层面          拼布层面
    （大块选布）       （精细填色）
    
    ┌─────────┐     ┌──────────────┐
    │ 正面→碎花 │     │ 正面拼布区域:  │
    │ 背面→牛仔 │     │  区块A→红波点  │
    │ 侧面→帆布 │     │  区块B→蓝格子  │
    │ 里布→纯棉 │     │  区块C→碎花    │
    │ 提手→皮革 │     │       ↳跟正面  │
    └─────────┘     │      同一块布!  │
                    └──────────────┘
```

**两层关联逻辑：**
- 包包层面选好正面用了"碎花棉布" → 拼布时某个区块也用"碎花棉布" → 合在一起算总用量
- 用料清单 = 包包面的用量 + 拼布区块的用量

## 六、数据全在本地，隐私安全

```
你的 iPhone
├── App 数据（IndexedDB）
│   ├── 分类 + 教程 + 链接
│   ├── 布料信息 + 标签
│   ├── 拼布方案 + 区块数据
│   └── 用料清单记录
│
└── 图片文件（浏览器存储）
    ├── 布料照片
    ├── 教程参考图
    ├── 纸样照片
    └── 包包封面图
```

- ✅ 所有数据在手机本地
- ✅ 没网也能用
- ✅ 以后加云同步，数据不会丢

## 八、技术信息（供参考）

| 项目 | 说明 |
|------|------|
| 类型 | PWA 网页应用（添加到 iPhone 主屏幕后全屏运行） |
